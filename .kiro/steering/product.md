# Product: Night Shift

Night Shift is an open-source "engineering org in a box": a skeleton crew of AI agents that builds software overnight while humans set intent and approve exceptions.

**Users.** Small teams and solo maintainers with more backlog than hours; enterprises piloting AI-first delivery.

**Promise.** Intent in, verified code out, and an honest count of how often a human had to step in (the Human Touch Index).

**Non-negotiables**
- Nothing is built from a vague requirement. The Spec Gate decides.
- A deterministic policy engine, never an agent, decides what merges.
- Every human touch is logged. We report failures as plainly as successes.
- Spooky is welcome; confusing is not. Every playful message ends with one clear next step.

**Apps built on the skeleton:** `apps/lazarus` (Resurrection: 2003 Perl CGI board rewritten with parity proof) and `apps/chimera` (Frankenstein: spreadsheet with formula, shell and HTTP cells).
