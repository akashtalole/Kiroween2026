# Night Shift power

Install in Kiro: **Powers panel → Add Custom Power → Import power from a folder** (this folder), or import from GitHub with this repository URL and the `powers/night-shift` path. Activates on keywords such as "spec gate", "merge policy", "evidence pack", "proof strength".

Skills: `spec-gate`, `policy-check`, `evidence-pack`, `touch-index`, `morning-briefing`, `proof-strength`.
The skills mirror `.kiro/skills/` in this repo (a test keeps them in sync). `policy-check` expects the policy engine at `examples/policy-engine/` in the workspace; outside this repo, copy that folder too.
